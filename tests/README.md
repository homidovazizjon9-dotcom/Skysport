# Тесты

```bash
python tests/run.py        # все наборы
python tests/run.py 03     # только набор, в имени которого есть "03"
```

Нужен установленный Chrome. Если он лежит в нестандартном месте:

```bash
CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe" python tests/run.py
```

Выход с кодом 1, если хоть одна проверка упала — годится для CI.

## Как это устроено

`run.py` берёт **настоящий** `index.html`, выбрасывает из него модуль Firebase
(в тестах сети нет), подставляет рядом настоящие `styles.css` и `app.js`,
вставляет в конец страницы тело набора из `suites/` и открывает всё это
в headless Chrome с `--dump-dom`. Набор пишет результат в `<pre id="__results">`,
раннер выдирает его между маркерами `@@RESULTS@@` и `@@END@@`.

Сборка складывается в `tests/.build/` и перезаписывается на каждом прогоне.

## Как писать проверки

В наборе доступен весь код приложения. Заготовка:

```js
ok('что проверяем', условие, 'что показать при падении');
```

Правила, на которых уже обжигались:

- **Результат пишется в конце набора.** `--dump-dom` снимает DOM после того,
  как отработают таймеры: раннер запускает Chrome с `--virtual-time-budget`,
  поэтому `setTimeout` и `await` внутри набора успевают завершиться.
- **Не писать `<script>` целиком в строке** — она закроет реальный тег.
  Разбивать: `'<scr' + 'ipt>'`.
- **Анимации в headless не проигрываются.** Проверять состояние данных
  и классы, а не итоговую прозрачность.
- Даты брать через `dateKey()`, а не `toISOString()` — иначе набор упадёт
  у того, кто живёт в другом часовом поясе.

## Наборы

| Файл | Что покрывает |
|------|---------------|
| `01-core.js` | Нормализация операций, рендер, экранирование, темы |
| `02-accounts-goals.js` | Счета, переводы, цели, удаление и отмена |
| `03-categories-history-receipt.js` | Свои категории, история, быстрый ввод, фото чека |
| `04-subscriptions-alerts.js` | Регулярные платежи, пропущенные месяцы, оповещения |
| `05-debts.js` | Долги: кому дали, у кого взяли, возврат, напоминания |
| `06-shared-access.js` | Совместный доступ: пути в базе, кэш, приглашения |
| `07-budget-rollover.js` | Перенос остатка бюджета, офлайн, установка |
| `08-ai-provider.js` | Выбор провайдера ИИ, перебор моделей, ошибки |
| `09-receipt-scan.js` | Окно распознавания чека: этапы, ошибки, повтор |
