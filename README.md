# Skysport
# 💰 Трекер расходов

Мобильное PWA-приложение для учёта расходов и доходов: аналитика, бюджет, цели накопления, регулярные платежи и ИИ-советы. Вход через Google, данные синхронизируются между устройствами через Firebase Realtime Database.

## 🚀 Быстрый старт

1. Опубликуй папку проекта на любом статическом хостинге (например, GitHub Pages, см. ниже)
2. Открой сайт и войди через Google
3. Добавь на главный экран телефона: **Поделиться → На экран «Домой»**

> Service Worker и вход через Google не работают при открытии файла напрямую (`file://`) — нужен http(s).

## 🔥 Настройка Firebase

1. Создай проект в [Firebase Console](https://console.firebase.google.com), включи **Authentication → Google** и **Realtime Database**
2. Подставь свой `firebaseConfig` в `index.html`
3. Добавь домен сайта в **Authentication → Settings → Authorized domains**
4. Задай правила базы данных, чтобы каждый пользователь видел только свои данные:

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "config": {
      ".read": "auth != null",
      ".write": false
    }
  }
}
```

### Структура данных

```
users/{uid}/transactions/{txId}   ← каждая операция отдельным ключом
users/{uid}/subscriptions         ← регулярные платежи
users/{uid}/goals                 ← цели накопления
users/{uid}/settings              ← валюта, бюджет, тема, лимиты категорий
config/groqKey                    ← ключ Groq для ИИ-анализа
```

Старый формат (транзакции массивом) автоматически переводится в новый при первом входе.

> ⚠️ Ключ Groq в `config/groqKey` доступен любому вошедшему пользователю. Для публичного использования вынеси вызов Groq в серверную функцию (Firebase Cloud Functions / Cloudflare Worker).
